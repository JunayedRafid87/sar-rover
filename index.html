Mapping Methodology

How each approach captures and reconstructs the environment

01

LiDAR Mapping

RPLiDAR C1 · 16 Layers · 360°

Full 360° structural scanning using a 16-layer rotating LiDAR. Produces a dense geometric point cloud ideal for navigation and obstacle mapping.

  • 720 horizontal × 16 vertical rays
  • 0.15m – 12m range
  • 2D occupancy grid for path planning
  • Lowest power draw (~32W)
02

RGB-D Mapping

Orbbec Astra Pro · 480×360 · 90° FOV

High-resolution depth + color camera captures detailed 3D reconstructions with real-world textures and colors, crucial for victim identification.

  • 480×360 resolution depth + RGB
  • Back-projected colored point cloud
  • ~100K+ points per frame
  • Consensus voxel accumulation
03

Hybrid Fusion

LiDAR + Orbbec · RTAB-Map SLAM

Combines the strengths of both sensors using RTAB-Map SLAM for robust loop closure, drift correction, and fused occupancy mapping.

  • LiDAR for 360° structure + navigation
  • RGB-D for colored 3D reconstruction
  • RTAB-Map sensor fusion (Grid/Sensor=2)
  • Loop closure for drift correction

⚠️ Known Limitations & Future Work

  • V4 struggled with white-hot polarity thermal images (inverted palette)
  • V5 added inverted polarity augmentation to address this gap
  • Low recall on distant/small subjects (sub-50px bounding boxes)
  • Background false positives (3,518 in V5) need further tuning
  • Future: multi-class detection (human, animal, vehicle, debris)
  • Future: integration with rover's onboard Orbbec camera feed
